# Special Education Needs

A green-and-white learning platform for special education exam preparation and professional learning.

## Project status
Initial web foundation (student-facing website) is being set up. Android app, admin panel, backend, authentication, payments, live classes, and video delivery are planned next phases.

## Design direction
- Clean minimal interface
- Green and white palette
- Hindi / English-ready content
- Responsive layout for mobile and desktop
- Accessibility-conscious typography and controls

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Important
The current starter uses sample course and test data. Do not enter real student data or payment credentials until authentication, database, and security controls are implemented.
